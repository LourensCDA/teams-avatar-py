# Changelog

## 1.1.0

- Done checks: yes/no checks per task, reported PASS/FAIL with evidence, gate every candidate before comparison. The Quality Bar section gains a `Done checks` list.
- Effort per role (`effort:` in config), with defaults and the reasons behind them.
- Task briefs written in plain coworker style with reasons and an example of good; no role-play, capitals or "double-check" lines.
- Judges and critics are told none of the work is theirs.
- `modes/lessons.md`: recurring gaps carried into every later brief.
- Handoff file and `--resume` for long runs; lead keeps only short reports in context.
- `/speckit.modes.bar` can interview the user when no bar is known yet.
- Completion report lists builder assumptions for the user to check.

## 1.0.0

- Initial release: direct, best-of-N and gauntlet modes; bar and tag commands.
